# Droitwich United Charities – website

Website for **Droitwich United Charities (DUC)**, registered charity no. 205536 – small grants for people and organisations in Droitwich Spa.

Built by Saltway Digital as a design concept.

## What's here
- `index.html` – the whole site (HTML, CSS and JavaScript in one file)
- `duc-logo.webp` – the DUC badge logo

## Admin panel
Click **⚙ Admin** (bottom right). Mockup password: `duc2026` (change it under *Settings & backup*).
From the admin panel you can edit every section, upload a logo, change colours and fonts, show or hide sections, manage grant enquiries, and copy or load all the content as a backup.

> Edits made in the admin panel are saved in the visitor's browser only (localStorage). A live site needs a server-side store and real sign-in.

## Hosting on GitHub Pages
Settings → Pages → Source: *Deploy from a branch* → `main` / root. The site will appear at
`https://droitwich-united-charities.github.io/Droitwich-United-Charities/`.
